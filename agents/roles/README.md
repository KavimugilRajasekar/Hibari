# Agent roles

Pick the role that fits the task and read its file after the ground rules (00). One agent may
hold several roles in one task; the rules of each apply.

| Role | File | Typical tasks |
|---|---|---|
| Engine developer | [engine_developer.md](engine_developer.md) | model code, tokenizer, inference, export, release tooling |
| Model developer | [model_developer.md](model_developer.md) | Koto data, configs, identity, behaviour, preparing training |
| Evaluator | [evaluator.md](evaluator.md) | suites, evaluation runs, reports, regression comparisons |
| Release engineer | [release_engineer.md](release_engineer.md) | profiles, GGUF export, backend parity, release readiness |
